CLI CONTRACT

Command:
uv run python -m src [--functions_definition <function_definition_file>] [--input <input_file>] [--output <output_file>]

functions input:
option: --functions_definition
Required/default: default
role: Provide the functions available for the LLM to choose
default path: data/input/functions_definition.json

test/prompt input:
option: --input
Required/default: default
role: Receive the prompts to feed the LLM
default path: data/input/function_calling_tests.json

output:
option: --output
Required/default: default
role: The file where to place the data generated by the LLM
default path: data/output/function_calling_results.json

OUTPUT ENTRY
prompt: (string) The original natural-language request
name: (string) The name of the function to call
parameters: (object) All required arguments with the correct types
